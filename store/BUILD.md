# Optional native wrapper
Install official Capacitor dependencies, copy capacitor.config.ts to the root, build the client, then run npx cap add android and/or npx cap add ios. Lock Android orientation to sensorLandscape and iOS to landscape left/right. Run npx cap sync and test safe-area/touch/audio/reconnect on real devices before building in Android Studio or Xcode.

macOS/Xcode is required for iOS. Accounts, signing keys, fees, privacy forms and actual submission require the owner. This scaffold does not establish that either native platform builds.
