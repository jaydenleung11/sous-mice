# N0 implementation contract
Types live in shared/protocol.ts; constants shared/constants.ts. All time in seconds except network serverTime in ms. Tick fixed 1/30. Positions tiles, map 72x48. JSON content only imported by shared/content.ts.

Content owner exports from shared/content.ts: MAP ({width,height,zones:[{id,name,x,y,w,h,color}],solids:[{x,y,w,h,mouseOnly?:boolean}],holes:[{id,x,y,room,junction}],hides:[{id,x,y,capacity}],objects:[{id,kind,x,y}],cages:[{id,x,y}],spawns:{mouse:{x,y},chef:{x,y}},stash:{x,y},pickups:[{id,food,x,y}],tunnelNodes:[{id,x,y}],tunnelEdges:[{from,to,length}]}), FOODS (Record<FoodId,{id,name,provision,buff?,duration?,uses?,tamper?,penalty?,counter?}>). Functions isWalkable(x,y,team,layer='floor',radius=0.3):boolean, hasLOS(a,b):boolean, zoneAt(x,y), nearestHole(x,y). All rooms floored within x1..70,y1..38; tunnel layer uses same x/y coordinates and only mice traverse it; hole use switches layer. Burrow at x26..45,y41..46. Tunnel layer allowed to move freely as wall-void routing abstraction; clients visualize graph. Solid prop footprints used for collisions, keep broad connected aisles. Content validates graph independently.

Simulation owner exports shared/sim.ts: createWorld(players:LobbyPlayer[],options:RoomOptions,seed?:number):World; stepWorld(world:World,inputs:Map<string,InputFrame>,dt?:number):void; movePlayer(player:Player,input:InputFrame,dt:number,world?:World):void (client prediction); contextAction(world:World,player:Player):{label:string,kind:string,target:string,duration:number}|undefined; damageChef(world,chef,amount):void; visibleTo(world,viewer,target):boolean. bots/index.ts exports botInput(world,player):InputFrame. Can add helper modules, tests/sim.test.ts owned by sim agent. No I/O inside sim. World stores absolute seconds in Until fields. NO network snapshots assembled by sim; server owns filtering.

Client owner implements entire client directory, Pixi scene, UI, audio, touch, tutorial, prediction. WebSocket URL import.meta.env.VITE_WS_URL or same-origin /ws. Sends protocol exactly. Root owns server + room transports. Local Vite proxies /ws to localhost:3001. Server sends 15Hz snapshots. Tutorial can use local simulation importing shared/sim.ts and botInput, clearly separate from online. No localhost fallback in production. Hero asset will be supplied at /art/hero.webp; use only if present (initially vector scene). Do not edit shared contract without coordinating. Root installs deps.

All agents own separate files; document limitations instead of claiming tests they did not run. Integrator owns STATE/DECISIONS and merge. All code under outputs/sous-mice.
