# Assets
All game vector artwork and synthesized audio are original project-created assets. Generated key art is recorded with prompt and provenance. Fredoka and Nunito fonts are distributed under the SIL Open Font License via @fontsource; license files are included in client/public/licenses and deployed with the game.
- Title art: original OpenAI built-in image generation; prompt recorded in ART_PROMPT.md; file client/public/art/hero.png.

V3 room geometry, characters, props, food, viewmodel, tunnel surfaces, and synthesized spatial audio are original project-created assets. Material textures are deterministically painted on local canvases; no third-party models/textures/music were downloaded. Three.js uses the MIT license; the package's license remains in its distribution. Existing font licenses continue to apply. No external character or film/game compositions were used.

October 8 cartoon update: revised mice, chef expressions, food silhouettes, painted textures and rounded counter edges are original procedural artwork. Supplied images were visual references for a warm cartoon style; no character models, textures, or compositions were copied. Resource decisions are recorded in ART-CARTOON.md.
